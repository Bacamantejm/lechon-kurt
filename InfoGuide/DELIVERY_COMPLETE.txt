## Getting Started (1 Hour)

### Step 1: Database Setup (5 min)
```
phpMyAdmin
→ Select lechon_db
→ Click "Import"
→ Upload LOGISTICS_MIGRATION.sql
→ ✅ 14 tables created
```

### Step 2: Get API Credentials (20 min)
- FoodPanda Partner Portal: Get API Key, Secret, Restaurant ID
- Grab Merchant Console: Get API Key, Partner ID, Restaurant ID

### Step 3: Configure in Admin (10 min)
```
Admin → Logistics → Settings
→ Enter FoodPanda credentials
→ Enter GrabFood credentials
→ Save
```

### Step 4: Setup Webhooks (20 min)
- Add FoodPanda webhook URL to FoodPanda Partner Portal
- Add GrabFood webhook URL to Grab Merchant Console
- Test webhooks

### Step 5: Verify (5 min)
```
Admin → Logistics
→ Should see empty dashboard
→ ✅ System is ready!
```

## Troubleshooting Guide

### Database Migration
- Check phpMyAdmin import was successful
- Verify all 14 tables exist
- Check for foreign key errors

### API Configuration
- Verify credentials are correct (copy-paste carefully)
- Check if using sandbox vs production
- Look in `logistics_api_logs` for error details

### Webhook Issues
- Verify webhook URL is HTTPS
- Test from provider's dashboard
- Check `logistics_api_logs` for incoming requests
- Review PHP error logs

### Status Updates
- Check database `logistics_tracking` table
- Review `logistics_tracking_history` for changes
- Verify admin has correct permissions
