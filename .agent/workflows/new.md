# New Task Initialization Workflow

## 1. Safety & Context Verification
- Read-only phase. Do not modify application source code during task initialization.

## 2. Step-by-Step Procedure
- **Read Context**: View `GEMINI.md` and documentation hubs to load tech stack rules, design tokens, and project guidelines.
- **Inspect Architecture**: Load existing route topography, domain services, or knowledge graph context before writing code.
- **Formulate Plan**: State clear task objectives and outline targeted files before execution.

## 3. Expected Output Specification
- Acknowledge project rules loaded and state initial plan cleanly without flowery language.

## 4. Verification Plan
- Verify no code changes were made during initialization.
